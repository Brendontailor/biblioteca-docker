O build

FROM node:20-alpine
WORKDIR /app
COPY package.json ./
RUN npm install --omit=dev
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

✓ Imagem base LTS e leve · cache de camadas · só dependências de produção.

Banco e persistência

init.sql

Montado em /docker-entrypoint-initdb.d/ como somente leitura. Cria a tabela e 3 livros só na primeira subida.

Volume pgdata

Montado em /var/lib/postgresql/data. Guarda os dados fora do container.

✓ Na segunda subida o log mostra Skipping initialization — prova de que o SQL não rodou de novo.

PostgreSQL + volume5 / 8

Fluxo de inicialização

1. docker compose up -d --build cria imagem, rede e volume

2. PostgreSQL sobe e executa o init.sql (volume vazio)

3. Healthcheck pg_isready confirma que o banco está pronto

4. A API sobe e conecta em db:5432

5. Navegador abre em localhost:3000
